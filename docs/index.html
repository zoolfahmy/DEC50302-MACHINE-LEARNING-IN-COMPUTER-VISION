Chapter 01

Foundations of Computer Vision

Why Python for CV?

Python is the de-facto language for Machine Learning and Computer Vision due to its simplicity and vast ecosystem of libraries. In DEC50302, we leverage two main pillars:

NumPy Handles matrix operations. Images are essentially matrices of pixel values.
OpenCV Open Source Computer Vision Library. Optimized for real-time image processing.

Core Image Operations

Before feeding data into a machine learning model, images must be pre-processed. Common techniques include:

  • ✓ Grayscale Conversion: Reduces complexity by removing color channels (3 channels -> 1 channel).
  • ✓ Resizing: Standardizing image dimensions for model input (e.g., 224x224 pixels).
  • ✓ Thresholding: Creating binary images to separate objects from backgrounds.
lab1_basics.py 
import cv2
import numpy as np

# 1. Load an Image
# '0' flag loads the image directly in Grayscale
img = cv2.imread('dataset/sample.jpg', 0)

# Check if image is loaded
if img is None:
    print("Error: Could not open or find the image.")
else:
    # 2. Resize the image
    # Resize to 50% of original width and height
    resized_img = cv2.resize(img, (0,0), fx=0.5, fy=0.5)

    # 3. Apply Gaussian Blur (Noise Reduction)
    blurred = cv2.GaussianBlur(resized_img, (5, 5), 0)

    # 4. Edge Detection (Canny)
    edges = cv2.Canny(blurred, 100, 200)

    # Display Result
    cv2.imshow('Edges', edges)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

Chapter 02

The Machine Learning Pipeline

Machine Learning is not magic; it is a structured process. Below is the standard pipeline used in this course to develop applications using Teachable Machines or TensorFlow.

📥

1. Collection

Gather raw data (Images, Videos). Diversity in data is key.

🧹

2. Preparation

Clean, label, and split data into Training (80%) and Testing (20%) sets.

⚙️

3. Training

Feed data into the model (CNN). The model learns patterns (features).

📈

4. Evaluation

Test model accuracy against unseen data. Tune hyperparameters.

🚀

5. Deployment

Integrate model into a Python App or Web Interface.

Chapter 03

Understanding Model Metrics

When training a Neural Network in TensorFlow, we monitor two key metrics: Loss and Accuracy.

The Loss Curve (Blue)

"Loss" represents the error. A lower loss means the model's predictions are closer to the actual labels. We want this line to go down over time (Epochs).

The Accuracy Curve (Red)

"Accuracy" is the percentage of correct predictions. We want this line to go up. If Training Accuracy is high but Validation Accuracy is low, the model is Overfitting (memorizing data instead of learning).
